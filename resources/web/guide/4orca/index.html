Stealth Mode
This disables all cloud features, including Orca Cloud profile syncing. Users who prefer to work entirely offline can enable this option.

Note: When Stealth Mode is enabled, your user profiles will not be backed up to Orca Cloud.
Anonymous Usage Statistics
Help show how many people use OrcaSlicer. Once a day, this installation is counted on a public dashboard. Only a hashed random ID and the program name are sent, never your files, settings or account.
Note: Stealth Mode turns this off. You can change this later in Preferences.
Turned off by Stealth Mode. Turned off by the TelemetryOptOut policy in the Windows registry. Turned off by the TELEMETRY_OPTOUT, ORCA_TELEMETRY_OPTOUT or TELEMETRY environment variable.
